# Raw drops

Сюда можно класть черновики (FBX, референсы и т.д.). Рабочий процесс:

1. Файл из `raw/` копируется в подходящее место, например `assets/models/basement/` (имя лучше `snake_case`). Для **glTF/GLB** рядом могут лежать внешние текстуры (`*.png`) — их тоже нужно скопировать в ту же папку, иначе материалы будут без карт.
2. Импорт: открыть проект в Godot или `Godot.exe --path . --import --headless`.
3. В сцену подключается импортированный `.glb` / `.gltf` как `PackedScene` (см. `scenes/basement/basement_hub.tscn`).

4. После копии **можно удалить файл из `raw/`**, чтобы папка оставалась только для временных дропов.

Коллизия по карте: `basement_map_collision.gd` **склеивает все меши карты в один `ArrayMesh`** и делает из него **один concave trimesh** плюс тонкий «страховочный» пол под AABB. Так пропадают микрозазоры между отдельными объектами (в Блендере пол цельный, а в движке отдельные `MeshInstance3D` давали «дыры» для персонажа).

Визуальные «дыры» у плит/шкафов часто не дыры в геометрии, а **backface culling**: в Blender видно обе стороны, в Godot по умолчанию рисуется только сторона по нормали. В сцене карта при старте получает **двусторонние** `StandardMaterial3D` (можно отключить флагом `materials_double_sided` на `BasementHub`). В импорте `test_map.glb` отключён **Generate LOD** — иногда упрощённые уровни дают пропажи граней на узкой геометрии.

В Blender на будущее: **Face Orientation**, затем **Recalculate Outside** / **Flip** для проблемных граней — это «правильное» решение без двусторонности в движке.
